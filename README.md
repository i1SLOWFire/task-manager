# Консольный Менеджер Задач (To-Do List)

[![Python Version](https://img.shields.io/badge/python-3.8%2B-blue)](https://www.python.org/)
[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)
[![Tests](https://img.shields.io/badge/tests-15%20passed-brightgreen)](tests/test_todo_manager.py)

Простой консольный менеджер задач на Python. Программа позволяет добавлять, просматривать, отмечать выполненные и удалять задачи. Все данные автоматически сохраняются в файл `tasks.json`.

---

## Установка и запуск

### Клонируйте репозиторий:

```bash
git clone --recursive https://github.com/i1SLOWFire/task-manager.git
cd task-manager
```
### Запустите программу:

```bash
python main.py
```

## Методы

| Метод          | Что делает                   |
| -------------- | ---------------------------- |
| `main()`       | Точка входа                  
| `see_task()`   | Показывает список задач.     |
| `add_task()`   | Добавляет новую задачу.      |
| `check_task()` | Отмечает задачу выполненной. |
| `del_task()`   | Удаляет задачу из списка.    |

## Тесты

Проект покрыт модульными тестами (`unittest`). Покрыты ключевые сценарии:

- Добавление, отметка и удаление задач
    
- Обработка ошибок ввода (не-число, пустая строка)
    
- Граничные случаи (пустое хранилище, неверный ID)
    
- Пересчёт ID после удаления

**Запуск:**
```bash
python -m unittest tests.test_todo_manager -v
```

Ожидаемый результат — 15 тестов, все успешно пройдены.
