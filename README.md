# Консольный Менеджер Задач (To-Do List)

Простой и надёжный консольный менеджер задач на Python. Программа позволяет добавлять, просматривать, отмечать выполненные и удалять задачи. Все данные автоматически сохраняются в файл `tasks.json`.

## Возможности

- ➕ Добавление новых задач с автоматической нумерацией ID.
- 📋 Просмотр всех задач с визуальным статусом (`[X]` — выполнено, `[ ]` — не выполнено).
- ✅ Отметка задачи как выполненной.
- 🗑️ Удаление задач.
- 💾 Автосохранение в JSON-файл после каждого изменения.
- 🛡️ Защита от некорректного ввода (буквы вместо цифр) и восстановление после повреждения файла.

## Технологии

- **Python 3.12+**
- Встроенная библиотека `json` для работы с файлами.
- Только стандартная библиотека — не требует установки внешних зависимостей.

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone <https://github.com/John1Kapika/task-manager.git>
   ```
2. Запустите программу
   ```bash
   python main.py
   ```

## Как использовать

После запуска в консоли появится меню с выбором действий. Просто введите номер нужного пункта и следуйте подсказкам на экране.

**Пример работы:**
   ```bash
  ------------------------------
  1. Добавить задачу
  2. Показать все задачи
  3. Отметить задачу выполненной
  4. Удалить задачу
  5. Выход

  Напишите номер действия: 1
  ------------------------------
  Опишите новую задачу: Купить хлеб
  Задача успешно добавлена.
  ```

## Структура проекта

- main.py — точка входа в программу.
- todo_manager.py — содержит всю бизнес-логику и работу с JSON.
- tasks.json — файл хранения задач (создаётся автоматически).
